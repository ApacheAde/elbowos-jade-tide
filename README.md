# Jade Tide

Full-colour Python 3 neon tide-hopper arcade for ElbowOS.

Hop a jade frog across scrolling neon currents filled with coral obstacles and gold orbs.

Left / Right / Up / Down (or A / D / W / S) to hop. R to restart.

## Play

```bash
pip install -r requirements.txt
python3 jade_tide.py --play
```

## Record a 9:16 reel

```bash
python3 jade_tide.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.

- Featured account: https://x.com/ElbowOS
- Repo: https://github.com/ApacheAde/elbowos-jade-tide
